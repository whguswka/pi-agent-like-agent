# 반입 검토 자료 — pi 코딩 에이전트 소스 (pi-agent-like-agent)

작성일: 2026-10-02

## 1. 개요
| 항목 | 내용 |
|---|---|
| 대상 | 오픈소스 코딩 에이전트 pi 0.87.1 (MIT) 와 사내 환경 연결용 스크립트 |
| 형태 | 소스 코드 모음 (깃헙 저장소 형식, zip 1개). 설치 프로그램·실행파일(exe, dll, msi 등)·바이너리 없음 |
| 목적 | 개발 업무 보조. 터미널에서 코드 읽기·수정·실행·테스트를 돕는 코딩 에이전트를 사내 LLM(vLLM) 또는 Copilot 웹 채팅과 연결해 사용 |
| 사용 위치 | ① Kubeflow JupyterLab 터미널 ② 업무 PC 의 Git Bash |
| 외부 의존성 | PyPI 패키지만 사용: `nodejs-wheel-binaries==24.19.0` (Node.js 실행환경. Node 20.15 이상이 이미 있으면 불필요) / 선택: `ripgrep==14.1.0` |

## 2. 구성
| 경로 | 내용 | 출처 |
|---|---|---|
| `runtime/` (835개 파일) | pi 0.87.1 실행 코드(JavaScript)와 pi 가 쓰는 JS 라이브러리 3종(chord, typebox, jiti) | npm 공식 배포본, 내용 수정 없음 |
| `bin/`, `compat/`, `install.sh`, `update.sh`, `check-node.sh` | 실행기, Node 탐색, Node 20 호환 보조, 설치·업데이트·진단 스크립트 (bash, JavaScript) | 자체 작성 |
| `profiles/` | 환경별 설정 템플릿(LLM 주소 등 JSON)과 pi 확장(`pc/.../jupyter.ts`, `copilot-session.ts`, 공통 `common/.../guard.ts`: 위험 명령 실행 전 확인, `modes.ts`: 계획·확인 모드, `undo.ts`: 고친 파일 되돌리기, `memory.ts`: 지침 파일에 기억할 것 적기, `files.ts`: 입력창 @파일 고르기·내용 붙이기, `notify.ts`: 작업 끝 알림, `kit.ts`: 도움말·상태 요약), 기본 지침·명령·스킬(Markdown) | 자체 작성 |
| `copilot/` | (업무 PC 전용) Copilot 웹 채팅 연동 중계기. 파이썬 표준 라이브러리만 사용 | 자체 작성 |
| `prompts/`, `skills/` | 기본 명령(프롬프트 템플릿) 6개와 기본 스킬 6개. 모두 Markdown 문서 (설치할 때 사용자 설정 폴더에 복사) | 자체 작성 |
| `tests/`, `docs/` | 단위 테스트, 문서 | 자체 작성 |

자체 작성 부분은 모두 사람이 읽을 수 있는 소스입니다 (압축·난독화 없음).

## 3. 동작 방식
- pi 는 사용자가 터미널에서 지시한 작업을 LLM 과 주고받으며 수행합니다. LLM 이 요청한 도구(파일 읽기·쓰기·수정, 셸 명령 실행)를 **사용자 계정 권한으로** 실행합니다. 이는 코딩 에이전트의 기본 기능입니다.
  - 되돌리기 어려운 작업(폴더 삭제, `git push`, `kubectl delete`, 패키지 제거, `sudo`, 작업 폴더 밖 파일 쓰기 등)은 실행 전에 사용자에게 확인을 받고, 거부하면 실행하지 않습니다 (확장 `guard.ts`).
  - 사용자가 고르면 더 조심스럽게 쓸 수 있습니다 (확장 `modes.ts`): 계획 모드는 읽기만 하고 계획을 세워 사용자가 승인한 뒤에 실행하고, 확인 모드는 파일을 바꾸거나 명령을 실행할 때마다 바뀌는 내용을 보여 주고 확인을 받습니다. pi 가 고친 파일은 `/undo` 로 되돌릴 수 있습니다 (확장 `undo.ts`).
- `jupyter` 설정: JupyterLab 터미널에서 실행합니다. LLM 은 설정 파일에 적은 사내 vLLM 주소입니다.
- `pc` 설정: 업무 PC 에서 실행합니다. pi 의 LLM 요청은 PC 내부 중계기(127.0.0.1:8765)가 받아, 사용자가 직접 로그인해 둔 Chrome(또는 Edge) 전용 창의 Copilot 탭에 질문을 입력하고 답을 읽어 돌려줍니다. 브라우저는 전용 프로필과 원격 디버깅 포트(127.0.0.1:9222)로 실행합니다.
  - Copilot 화면의 모델 메뉴에서 사용자가 pi 에서 고른 모델을 선택합니다 (새 채팅마다 '자동' 으로 돌아가기 때문).
  - pi 세션이 끝나면 그 세션이 만든 Copilot 대화를 사용자 계정의 대화 목록에서 삭제합니다. 중계기가 만든 대화만 기록해 두고 그것만 지우며, 설정(`delete_finished_chats`)으로 끌 수 있습니다.
  - `pi --jupyter <폴더>` 로 실행하면, 사용자가 열어 둔 JupyterLab 탭을 통해 노트북 터미널(`pibridge`)에서 명령을 실행하고 Jupyter 파일 기능으로 파일을 읽고 씁니다. 노트북에는 아무것도 설치하지 않습니다.

## 4. 네트워크 접속
| 구성요소 | 접속 대상 | 비고 |
|---|---|---|
| pi (`jupyter` 설정) | 사내 vLLM 주소 (설정 파일 `~/.pi/agent/models.json`) | 그 외 자동 접속은 끔 (아래) |
| pi (`pc` 설정) | 127.0.0.1:8765 (PC 내부 중계기) | |
| 중계기 (`copilot/`) | 127.0.0.1:9222 (전용 브라우저 창의 원격 디버깅) | 127.0.0.1 에서만 접속을 받음. 조작 대상은 사용자가 연 Copilot·JupyterLab 페이지 |

- 자동 네트워크 활동을 끕니다: 실행기가 `PI_OFFLINE=1`(모델 목록 갱신 등 자동 네트워크 활동 끔)과 `PI_SKIP_VERSION_CHECK=1`(pi.dev 최신 버전 확인 끔)을 설정하고, 설정 템플릿에 `enableInstallTelemetry: false`(익명 설치·업데이트 통계 끔)를 넣었습니다. 각 설정의 의미는 pi 공식 문서(`runtime/docs/`) 기준입니다.
- 자체 작성 코드는 외부(인터넷) 주소로 직접 접속하지 않습니다.

## 5. 원본 동일성 확인 방법
`runtime/` 의 파일은 아래 npm 공식 배포본에서 실행에 필요한 파일만 골라 그대로 넣었습니다. 2026-10-02 에 포함한 835개 파일 모두 공식 배포본 안의 같은 파일과 sha256 이 일치함을 확인했습니다.

| 패키지 | 버전 | 배포 주소 | 원본 소스 저장소 |
|---|---|---|---|
| `@earendil-works/pi-coding-agent` | 0.87.1 | https://registry.npmjs.org/@earendil-works/pi-coding-agent/-/pi-coding-agent-0.87.1.tgz | https://github.com/earendil-works/pi |
| `@earendil-works/chord` | 0.87.1 | https://registry.npmjs.org/@earendil-works/chord/-/chord-0.87.1.tgz | https://github.com/earendil-works/pi |
| `typebox` | 1.3.27 | https://registry.npmjs.org/typebox/-/typebox-1.3.27.tgz | https://github.com/sinclairzx81/typebox |
| `jiti` | 2.7.0 | https://registry.npmjs.org/jiti/-/jiti-2.7.0.tgz | https://github.com/unjs/jiti |

확인 절차 (인터넷 PC):
1. 배포 주소에서 `.tgz` 를 내려받아 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md) 의 sha512 와 비교합니다. (Windows: `certutil -hashfile 파일.tgz SHA512`)
2. 압축을 풀어 [runtime-SHA256SUMS.txt](runtime-SHA256SUMS.txt) 의 파일별 sha256 과 비교합니다.
   `runtime/` 는 pi 패키지의 `package/`, `runtime/node_modules/<이름>/` 은 해당 패키지의 `package/` 에 대응합니다.

## 6. 백신 검사 관련
pi 는 셸 명령을 실행하는 코딩 에이전트이고, 배포본은 여러 모듈을 하나로 묶고 압축(minify)한 JavaScript 입니다. 프로세스 실행 코드와 압축된 코드가 함께 있어, 일부 백신의 휴리스틱(행위 추정) 검사에서 의심 파일로 분류될 수 있습니다. 이 경우 5번 방법으로 공식 배포본과 같은 파일인지 확인해 주시기 바랍니다.
