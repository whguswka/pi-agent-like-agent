# API 판 수동-작업-절차.md 조각

원래 키트 문서의 `api:바꾸기 이름`·`api:넣기 이름` 표시 자리에 API 판에서 들어갈 글입니다 (`api-kit/assemble.mjs` 가 씀).
'조각: 이름' 주석 줄로 나누고, 조각 끝의 빈 줄은 빼고 읽습니다. 첫 조각 위의 이 글은 읽지 않습니다.

<!-- 조각: 2장-순서 -->
1. zip 을 노트북에 올립니다: code-server 왼쪽 탐색기의 홈 폴더(`/home/jovyan`)에 끌어다 놓기 (안 되면 폴더를 오른쪽 클릭 > **Upload...**).
   이름이 `pi-agent-like-agent-api-main (1).zip` 처럼 바뀌었으면 아래 명령의 이름도 바꿉니다. 이미 `~/tools/pi` 가 있으면 3장으로 갑니다.
2. 풀고 설치합니다:
   ```bash
   cd ~ && mkdir -p ~/tools && python -m zipfile -e ~/pi-agent-like-agent-api-main.zip ~/tools/ && mv ~/tools/pi-agent-like-agent-api-main ~/tools/pi
   bash ~/tools/pi/check-node.sh
   bash ~/tools/pi/install.sh
   ```
   - `check-node.sh` 의 마지막 줄이 `결과: 사용 가능` 또는 `결과: 호환 모드로 사용 가능` 이면 됩니다.
     `결과: 사용 가능한 Node 없음` 이면 화면의 방법대로(또는 [README 2-3](../README.md#2-3-nodejs-확인)) 준비한 뒤 `install.sh` 를 다시 실행합니다.
3. 터미널을 **새로** 열고 `pi --version` (판 번호가 나오면 설치된 것).
4. LLM 서버를 적습니다: `~/.pi/agent/models.json` 의 주소·모델 이름, `settings.json` 의 `defaultModel` ([README 2-5](../README.md#2-5-llm-연결), [API 연결](API-연결.md)). 이어서 연결 확인:
   ```bash
   cd ~ && pi -p "bash 로 echo hello 를 실행하고 결과를 알려줘"
   ```
5. 작업 폴더에서 `pi` 를 실행하고 `hello.py 를 만들어서 hello 를 출력하고 실행해줘` → 파일이 생기고 결과가 나오면 끝입니다.
   시작 화면의 `Warning: fd not found ...`, `Warning: ripgrep not found ...` 두 줄은 늘 나오는 것이니 무시합니다.
6. (한 번) `Shift+Enter` 가 줄을 바꾸지 않고 바로 보내면 [README 3-3](../README.md#3-3-code-server-터미널에서-다르게-쓰는-키) 의 키 설정을 합니다.
7. 안 되면 8장.

<!-- 조각: 5-2-명령 -->
2. 아래를 실행합니다. 둘째 줄은 지금 판에만 있던 키트 확장을 `extensions.removed` 로 옮깁니다 (직접 만든 확장은 그대로).
   ```bash
   cd ~ && rm -rf ~/tools/pi.new && mv ~/tools/pi ~/tools/pi.new && mv ~/tools/pi.old ~/tools/pi && bash ~/tools/pi/install.sh
   cd ~/.pi/agent/extensions && for f in $(cd ~/tools/pi.new/profiles/common/agent-template/extensions && find . -name '*.ts' | sed 's#^\./##'); do [ -e "$f" ] && [ ! -e ~/tools/pi/profiles/common/agent-template/extensions/"$f" ] && mkdir -p "../extensions.removed/$(dirname "$f")" && mv "$f" "../extensions.removed/$f" && echo "치움: $f"; done; cd ~
   ```
