# 반입 검토 자료 — pi 코딩 에이전트 소스 (pi-agent-like-agent-api)

<!-- 조각: 3장-설정 -->
- LLM 은 사용자가 설정 파일(`~/.pi/agent/models.json`)에 적은 OpenAI 호환 API 서버입니다. pi 는 지침, 요청, 읽은 파일 내용, 명령 결과를 그 서버로 보내고 답을 받습니다.
- 설치는 사용자 홈 아래(`~/tools/pi`, `~/.pi/agent`)에만 파일을 두고, 셸 시작 파일(`~/.bashrc`, `~/.profile`)에 PATH 한 줄을 더합니다. 관리자 권한이나 시스템 영역 쓰기는 없습니다.
- 공용 확장(`profiles/common`)은 이 키트의 바탕인 pi-agent-like-agent 와 같은 파일입니다. 그 저장소에서 웹 채팅 연결 프로그램을 거쳐 원격 노트북의 파일을 다루던 분기(`lib/relay.ts` 의 원격 분기, 127.0.0.1 로만 접속)가 코드에 남아 있지만,
  이 키트에는 그 분기를 켜는 확장과 연결 프로그램이 들어 있지 않아 실행되지 않습니다.
