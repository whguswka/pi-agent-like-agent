description: 바뀐 내용으로 커밋 메시지를 써서 커밋 (push 는 하지 않음)
argument-hint: "[메시지에 담을 내용]"
---
작업 폴더의 변경 사항을 커밋해 주세요.
1. `git status`, `git diff --stat`, 필요한 diff 를 보고 무엇이 바뀌었는지 파악합니다.
2. 커밋하면 안 되는 파일(비밀번호·키가 든 파일, 큰 데이터, 임시 파일)이 있으면 커밋하지 말고 먼저 알려 줍니다.
3. 커밋 메시지: 첫 줄은 무엇을 했는지 50자 안팎의 한국어로, 필요하면 빈 줄 뒤에 왜·어떻게를 개조식으로 씁니다. 참고할 내용: ${@:-없음}
4. 관련 파일만 `git add` 하고 `git commit` 합니다. push 는 하지 않습니다.
