# 공통 지침

pi-agent-like-agent 를 처음 설치할 때 만든 기본 지침입니다. 자유롭게 고쳐 쓰세요 (업데이트해도 이 파일은 바뀌지 않습니다).

## 답하는 방식
- 한국어로 답한다.
- 작업을 마치면 한 일, 바꾼 파일, 확인한 방법(실행한 명령이나 테스트)을 짧게 정리한다.
- 요청이 모호하거나 되돌리기 어려운 작업(삭제, 많은 파일 변경, 배포)은 먼저 계획을 말하고 확인을 받는다.

## 작업 환경
- Kubeflow JupyterLab 노트북(리눅스) 안이다. 홈(`~`)은 영구 저장소라 파드를 다시 시작해도 남고, 그 밖(`/tmp`, 기본 conda 환경 등)은 사라질 수 있다.
- 사내 폐쇄망이다. 인터넷 주소로 접속하거나 외부에서 내려받는 명령(외부 주소 curl·wget, 외부 git clone 등)은 쓰지 않는다.
- Python 패키지는 사내 PyPI 미러로만 설치된다. 설치가 필요하면 먼저 알리고 `pip install --user <패키지>` 로 설치한다 (`--user` 가 없으면 파드를 다시 시작할 때 사라진다).
- 명령은 입력 없이 실행된다. 입력을 기다리는 명령(vi, less, 인자 없는 python 등)은 쓰지 않는다. 오래 걸리는 작업은 `nohup ... > 로그파일 2>&1 &` 로 띄우고 로그를 확인한다.

## 빠르게 일하는 방법
- 큰 파일은 통째로 읽지 말고 `grep -n` 으로 위치를 찾은 뒤 필요한 부분만 읽는다 (read 의 offset·limit).
- 작은 수정은 edit 로 바꿀 부분만 고친다. 파일 전체를 다시 쓰는 것은 새 파일이거나 대부분을 바꿀 때만 한다.
- 출력이 길어질 명령은 `| head -50` 이나 `| tail -50` 으로 줄인다.
- 고친 뒤에는 실행하거나 테스트해서 확인한다.
